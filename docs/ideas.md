# ESP32 活用プロジェクトアイデア集

お手元の「ESP32 + ネジ留め端子台付き拡張ボード」の特性（ハンダ付け不要、Wi-Fi/Bluetooth内蔵、デュアルコア240MHz）を最大限に活かせる工作アイデア集です。

---

## 1. 🎛️ 自作マクロキーボード（左手デバイス）

ネジ留め端子台にキースイッチやボタンを直接配線し、ESP32をワイヤレスマクロパッドとして動作させる。

### 特徴・できること
* **Bluetooth BLE HID機能**: PCやiPadとワイヤレス接続可能。
* **ショートカット送信**: 1ボタンで「Ctrl+C」「Ctrl+V」「マイクのミュート切り替え」「DiscordのPTT」「定型文入力」などを送信。
* **配線の強み**: 拡張ボードのスクリューターミナルにメカニカルキースイッチやアーケードボタンの線を直接ネジ留めするだけ（ハンダ付け不要）。

---

## 2. 📺 スマートデスククロック ＆ 情報看板

安価な「0.96インチ OLEDディスプレイ（SSD1306）」を4本のネジ留め配線で接続。

### 配線（I2C接続 / ネジ留め4本のみ）
* `VCC` ➔ **3V3**
* `GND` ➔ **GND**
* `SDA` ➔ **D21**
* `SCL` ➔ **D22**

### 特徴・できること
* **NTP自動時刻合わせ時計**: Wi-Fi経由でネット上の時刻サーバーと同期し、電波時計並みに正確な卓上時計に。
* **天気予報表示**: お天気APIから「今日の気温・降水確率・アイコン」を取得して表示。
* **PCステータスモニター**: PC側の常駐スクリプトからCPU使用率やメモリ残量、GPU温度を受信してリアルタイム描画。
* **ミニ卓上サイン**: 「離席中」「取込中」「作業中」などをボタンで切り替えて表示。

---

## 3. 🔔 スマート卓上通知ガジェット（メール・新着アラート）

PCの作業中やゲーム中でも、視界の隅で新着メッセージや重要メールを光・画面・音で知らせてくれるデバイス。

### 構成要素
1. **OLED画面表示**:
   * メールの「差出人・件名」
   * Discord / Slack / LINE の新着通知
   * カレンダーの予定リマインダー（「10分後にミーティング」など）
2. **光と音のアラート**:
   * 新着検知時に内蔵青色LED（GPIO 2）や外付けLEDが点滅
   * 小型圧電ブザーを端子台に追加すれば「ピピッ♪」と控えめな電子音でお知らせ
3. **物理操作**:
   * 基板上の **[BOOT] ボタン**（または外付けボタン）を押すと、アラート停止＆画面クリア（「既読」状態）に。

### 実装アプローチ
* **PC連携型**: PC上のPythonスクリプトが通知を検知し、USBシリアルまたはWi-FiでESP32に送信。
* **単独動作型**: ESP32が直接Wi-Fi経由で Google Apps Script (GAS) や Webhook を定期チェック。
