# ESP32 30ピン（DOIT DevKit V1 互換）ピンアサイン早見表

お手元のボード（片側15ピン・計30ピン）に完全対応したピンレイアウト表です。  
ブレッドボードやセンサーを接続する際のリファレンスとしてご活用ください。

---

## 📌 ピン配置図（USBコネクタを上にした場合）

```
                     ┌──────────────────┐
                     │    [  USB  ]     │
                     │                  │
           [ EN ] ───┤                  ├─── [ BOOT ]
                     │  ESP-WROOM-32    │
         (Reset) EN  │ [1]          [1] │ D23 (GPIO 23)
 (入力専用) SENSOR_VP │ [2]          [2] │ D22 (GPIO 22) [I2C SCL]
 (入力専用) SENSOR_VN │ [3]          [3] │ TX0 (GPIO 1)  [UART TX]
      (入力専用) D34 │ [4]          [4] │ RX0 (GPIO 3)  [UART RX]
      (入力専用) D35 │ [5]          [5] │ D21 (GPIO 21) [I2C SDA]
  (アナログOK)   D32 │ [6]          [6] │ D19 (GPIO 19) [SPI MISO]
  (アナログOK)   D33 │ [7]          [7] │ D18 (GPIO 18) [SPI SCK]
       (DAC/音声) D25 │ [8]          [8] │ D5  (GPIO 5)  [SPI CS]
       (DAC/音声) D26 │ [9]          [9] │ TX2 (GPIO 17) [UART2 TX]
                 D27 │ [10]        [10] │ RX2 (GPIO 16) [UART2 RX]
                 D14 │ [11]        [11] │ D4  (GPIO 4)
           (※注) D12 │ [12]        [12] │ D2  (GPIO 2)  [内蔵LED]
                 D13 │ [13]        [13] │ D15 (GPIO 15)
            (電源) GND │ [14]        [14] │ GND (電源)
      (5V入力)   VIN │ [15]        [15] │ 3V3 (3.3V出力)
                     └──────────────────┘
```

## 📋 ピン機能詳細一覧

### 【左側ピン列（上から下へ）】
| ピン番号 | シルク表記 | GPIO番号 | 主な機能・おすすめ用途 | 備考・注意点 |
| :---: | :--- | :---: | :--- | :--- |
| 1 | **EN** | - | チップリセット | 外部からリセットスイッチを繋ぐ場合に利用 |
| 2 | **VP** | GPIO 36 | アナログ入力 (ADC1_0) | **入力専用**（出力不可、内部プルアップなし） |
| 3 | **VN** | GPIO 39 | アナログ入力 (ADC1_3) | **入力専用**（出力不可、内部プルアップなし） |
| 4 | **D34** | GPIO 34 | アナログ入力 (ADC1_6) | **入力専用**（出力不可、内部プルアップなし） |
| 5 | **D35** | GPIO 35 | アナログ入力 (ADC1_7) | **入力専用**（出力不可、内部プルアップなし） |
| 6 | **D32** | GPIO 32 | 汎用入出力 / ADC1_4 | Wi-Fi動作中も安全に使えるアナログ入力 |
| 7 | **D33** | GPIO 33 | 汎用入出力 / ADC1_5 | Wi-Fi動作中も安全に使えるアナログ入力 |
| 8 | **D25** | GPIO 25 | 汎用入出力 / DAC1 | アナログ電圧出力（スピーカー音声出力など） |
| 9 | **D26** | GPIO 26 | 汎用入出力 / DAC2 | アナログ電圧出力（スピーカー音声出力など） |
| 10 | **D27** | GPIO 27 | 汎用入出力 / タッチ | 癖がなく安全に使える |
| 11 | **D14** | GPIO 14 | 汎用入出力 / HSPI_CLK | 汎用ピンとして安全 |
| 12 | **D12** | GPIO 12 | 汎用入出力 / HSPI_MISO | ※起動時にHighだとフラッシュ電圧設定が変わり起動失敗する恐れあり |
| 13 | **D13** | GPIO 13 | 汎用入出力 / HSPI_MOSI | 汎用ピンとして安全 |
| 14 | **GND** | - | グラウンド (0V) | センサー等のGNDと接続 |
| 15 | **VIN** | - | 5V電源入力 | USBからの5Vがそのまま出力されているピン（外部給電も可） |

## 💡 配線時のクイックアドバイス

1. **センサー（I2C通信: OLEDディスプレイ、温湿度センサーなど）をつなぐ場合:**
   * `SDA` ➔ **D21**
   * `SCL` ➔ **D22**
   * `VCC` ➔ **3V3**
   * `GND` ➔ **GND**
2. **アナログ電圧を測りたい場合（光センサー、可変抵抗など）:**
   * Wi-Fiと干渉しない **D32 / D33 / D34 / D35 / VP / VN** を使ってください。
3. **LEDやブザーを鳴らしたい場合（出力）:**
   * **D4, D13, D14, D27** などが制約がなく一番使いやすいです。
   * ※VP, VN, D34, D35 は入力専用のため出力には使えません。
